Offensive Security Home Lab

🗓 Mar 2026 ⚙ KVM 🛡 pfSense 🐉 Kali Linux 🧪 Metasploitable 🪟 Windows Server 🏢 Active Directory 💻 Windows Client

Project Overview

This home lab is built to simulate a small enterprise-style environment for practising offensive security techniques inside a safe and isolated network. The infrastructure includes pfSense for firewall and routing, Kali Linux as the attacker workstation, Metasploitable as a vulnerable Linux target, and a Windows Server Active Directory environment with a joined Windows client.

The goal is to create a realistic space for network enumeration, service discovery, exploitation, privilege escalation, and Windows domain-focused testing while keeping all activity separate from the host operating system and home network.

Lab Architecture

The environment uses pfSense as the gateway between the default NAT network and an isolated internal lab segment. All attacker and target systems live on the internal network, allowing safe communication without exposing the host operating system or home network to lab activity.

Virtualization Platform

The environment is hosted on a Linux system using KVM/QEMU virtualization and managed through virt-manager. This makes the lab easy to snapshot, rebuild, and expand as new machines and services are added.

  • Hypervisor: KVM / QEMU
  • Management interface: virt-manager
  • Firewall: pfSense
  • Attacker: Kali Linux
  • Linux target: Metasploitable
  • Windows infrastructure: Windows Server + Active Directory
  • Client system: Windows 10 / 11 joined to the domain
virt-manager showing the full lab environment and virtual machine inventory.

Lab Machines

pfSense Firewall Gateway, routing, DHCP, and network isolation
›

pfSense provides routing, DHCP, and internal network control for the lab. The WAN interface receives an address from the default NAT network, while the LAN interface is configured on the isolated lab segment as 192.168.50.1/24.

  • WAN: vtnet0 on the default NAT network
  • LAN: vtnet1 on lab-net
  • LAN IP: 192.168.50.1/24
  • DHCP range: 192.168.50.100 - 192.168.50.200

  • Role: Domain Controller
  • Services: Active Directory, DNS, domain management

  • Use case: Support realistic Windows lab architecture

Outcome

This lab provides a practical foundation for developing offensive security skills in a safe, controlled, and expandable environment. It combines network infrastructure, Linux targets, and Windows domain services into a single portfolio project that can grow as new machines, services, and attack paths are added.
