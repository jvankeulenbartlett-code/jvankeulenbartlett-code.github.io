Project: Home Lab – Identity & Network Security Environment

I built a segmented cybersecurity home lab to practice real offensive security workflows. The lab includes Active Directory, Windows Server, and multiple internal networks so I can simulate attacks, perform enumeration, and practice privilege escalation safely.

The environment is used to study identity infrastructure, network segmentation, and penetration testing methodology in a controlled setting.
