Project: Offensive Security Home Lab (KVM + pfSense)

I built a practical offensive security home lab using KVM virtualization, a pfSense firewall, Kali Linux, and a Metasploitable target machine. The lab is designed to simulate a small segmented environment where I can safely practise network discovery, service enumeration, exploitation, and basic post-exploitation workflows.

pfSense is used to manage routing and segmentation between lab networks, while Metasploitable provides an intentionally vulnerable host for testing enumeration and exploitation from a Kali attacker VM.
