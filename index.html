Project: Offensive Security Home Lab (KVM + pfSense)

I built a practical offensive security home lab using KVM virtualization, a pfSense firewall, Kali Linux, and a Metasploitable target machine. The lab simulates a segmented enterprise environment where I can practise network discovery, enumeration, exploitation and post-exploitation techniques.
